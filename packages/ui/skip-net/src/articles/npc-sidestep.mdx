#### npc-sidestep

```sh
# start it, or retune it
sidestep

# the kind of step, and where they go back to
sidestep kind:turn back:home

# a kind, tuned
sidestep kind:wall reach:2

# whom the lookout tested since last asked
sidestep status

# stop it
sidestep off
```

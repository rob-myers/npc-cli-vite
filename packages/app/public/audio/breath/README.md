# Breath samples

Four breaths in and five out, cut from "inhaleExhale" by takareads, https://freesound.org/people/takareads/sounds/847471/.
Each is mono, levelled, faded at both ends and re-encoded as 64 kbps mp3 at 22.05 kHz. `out-0` is the calmest, `out-4` the hardest.

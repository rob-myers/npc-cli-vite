This is <Abbr title="Non Player Character">NPC</Abbr> <Abbr title="Command Line Interface">CLI</Abbr> -- NPCs driven from an in-browser JavaScript shell, wrapping hot-reloaded TypeScript in DEV.

Built with three.js WebGPU, React Three Fiber, Navcat, Mvdan/sh, Xterm.js and Vite.
Maps are made in MapEdit (inspired by Boxy SVG) from symbols based on [Starship Geomorphs 2.0](https://travellerrpgblog.blogspot.com/2020/07/starship-geomorphs-20.html).

By **Robert S. R. Myers** · [rob-myers/npc-cli-vite](https://github.com/rob-myers/npc-cli-vite)
